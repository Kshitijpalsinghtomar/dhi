# DHI — Model Research & Development

DHI is the model-development programme for a general-purpose, tool-aware, long-horizon predictive agentic model. The objective is to improve the model's learned intelligence—not to market a system prompt, RAG collection, or external orchestrator as a new model.

## Research principle

A result advances only when a mechanism, frozen protocol, strong baseline, held-out test, raw evidence, and independent metric calculation support it. Negative and inconclusive results remain recorded. A 100% target on a fixed benchmark is a stretch goal, not a promise of universal perfect performance.
